
# AI Gesture-Controlled Computer Assistant

## Project Description
A Python-based application that uses a webcam to recognize hand gestures and control computer functions.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy

## Features
- Hand detection and tracking
- Mouse cursor movement
- Mouse click using gestures
- Presentation slide navigation
- Future scope: volume control and more gestures

## How to Run
1. Install the required libraries.
2. Run `python main.py`.
3. Show your hand in front of the webcam.
4. Press Q to quit the application.
